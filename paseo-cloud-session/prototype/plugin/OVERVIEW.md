Prototype provider for a remote (cloud) session. Each agent of this provider is a placeholder: the daemon's inputs (session open, prompts, interrupts) are kept in an in-memory queue that a remote caller drains with the `probe.poll` RPC, and the remote caller produces the agent's timeline and turn state with `probe.push` and `probe.emit`. Prompts that arrive during an open turn are accepted as steering into that turn.

The `probe.mcp` RPC forwards one JSON-RPC message to the placeholder agent's own Paseo MCP endpoint on this machine, so the remote caller can use Paseo tools as that agent. The endpoint address and its bearer token stay in plugin memory and never appear in RPC results, the queue, or logs. The plugin makes no other network requests and loses its state when the plugin process restarts.
