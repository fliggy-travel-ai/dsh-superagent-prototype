Prototype provider for a remote (cloud) session. Each agent of this provider is a placeholder: the daemon's inputs (session open, prompts, interrupts) are kept in an in-memory queue that a remote caller drains with the `probe.poll` RPC, and the remote caller produces the agent's timeline and turn state with `probe.push` and `probe.emit`. The plugin stores no credentials, makes no network requests, and loses its queue when the plugin process restarts.
