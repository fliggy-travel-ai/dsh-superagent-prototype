# 开发自动化

插件沿用 `github-subscriptions` 标识。侧边栏入口为「开发自动化」，包含概览、问答模式、浏览器分组、GitHub 订阅、人工待办和最近动作。

## 在线与离线问答

「问答模式」统一处理 Paseo 原生提问和已配对浏览器里的 Claude Code 提问。原生权限自动确认只执行已有的会话精确授权策略，没有匹配策略的请求保留人工处理。

- 自动：读取所选主机的手机蓝牙在场状态。
- 在线：在所选主机语音提醒，等待用户回答。
- 离线：只选择问题中明确标记的推荐项。没有推荐项时留在人工待办。

自动模式读取 `~/.claude-guard/proximity-state.json` 和 `auto-answer.flag`。状态超过两分钟、没有有效信号或两份状态尚未同步时显示「判定未知」，等待用户回答。有效手动覆盖优先。跨主机读取和语音使用已有 Paseo 主机连接，两台主机都需要安装本版插件；断连时显示原因。

在「问答模式 → 蓝牙锚定设备」中刷新设备列表，选择随身手机或手表。设备来自所选的来源主机；列表显示地址末尾、连接状态和信号强度。也可以输入系统蓝牙列表中的完整名称。同名设备有多台时，应从列表按地址选择。暂时未发现设备时保留原选择。

选择保存到来源主机的 `~/.claude-guard/proximity-target.json`。来源主机需运行本仓库 `scripts/proximity-away.py` 采样器，且与 Paseo 使用同一 macOS 用户。采样器每 30 秒读取目标；切换设备后重新累计时间，信号持续不低于 −78 dBm 60 秒判为在线，持续不高于 −88 dBm 120 秒判为离线。新设备尚未形成稳定判定、没有信号或配置版本不一致时保持未知。设备显示「已连接」不代表系统提供了信号强度。

人工待办显示来源、会话名称、问题和选项，支持单选与多选。原生回答按请求编号提交，最多等待十秒回执。网页回答核对会话、问题内容和有效期；「已提交」表示扩展已操作页面，不能证明 Claude 已处理。结果未知时不自动重试。暂停或切换模式会取消尚未下发的网页回答。登录、两步验证和安全验证仍由用户处理。

## 人工待办与停滞会话

人工待办保留未回答、正在提交和结果未知的问题。人工回答经原生宿主确认后自动移出；网页回答需要扩展完整读取同一会话，确认问题已消失后才移出。关闭标签页、读取失败或只点击提交都不作为完成证明。

自动代答完成后继续显示问题、选择的答案和「已读」按钮。点击「已读」表示用户已知悉，随后移出待办；已读状态重启后仍有效。结果未知时显示核查提示，不重复提交。

验收结论、合并授权、资源清理、资金、登录和访问权限问题均留待用户本人确认。代答记录不能作为用户本人的授权证明。完整扫描确认原问题已经结束后，未知结果会转为已处理，并保留未确认说明；自动代答仍等用户点已读。

「网页等待处理」展示已配对网页的等待输入或用量限制提示及最后消息。只采用最近九十秒的状态；已有问答的网页不重复显示。网页后台子任务和监听仍需打开原会话核对，不自动续推或换账号。

## 语音提醒

语音沿用原方案的 Glass 提示音、晓晓中文神经语音和三分钟冷却。神经语音失败时回退到系统 Flo 语音。来源主机需要 Python 的 edge_tts 模块；可用 `ASKUSER_PYTHON` 和 `ASKUSER_VOICE` 指定解释器和声音，并沿用来源主机的代理设置。未指定解释器时，优先使用可执行的 `~/.claude-guard/speech-venv/bin/python3`，没有可用专用环境时使用 PATH 中的 `python3`。

专用语音环境在来源主机上准备，不安装到系统 Python。选择已核验能通过本机代理访问语音服务的 Python，执行 `python3 -m venv ~/.claude-guard/speech-venv`，再执行 `~/.claude-guard/speech-venv/bin/python3 -m pip install edge-tts==7.3.1`。插件不会自行安装或升级依赖。替换环境后，下一次播放自动使用该环境，无需重启 Paseo 守护进程；重新部署时保留整个 `~/.claude-guard` 目录。

只有语音播放进程成功退出才记录已提醒。提示音成功不算语音成功；失败保留原因，三分钟后可以重试。成功记录保存在来源主机，插件重启后不重复提醒同一道题。播放历史区分神经语音、系统语音、失败和取消。

关闭语音、暂停、切换模式或声音主机、问题结束时，会取消对应提醒。跨主机播放超时也会发送取消；来源主机断连时无法保证立即停止，界面会保留失败原因。插件只能确认播放进程的结果，不能确认用户实际听到声音。

「停滞主会话」显示本机未归档、没有父会话标签的主会话。主会话没有活动轮次和待处理请求，跨主机子孙会话与提供方子代理都不在工作，且整个会话家族没有有效 GitHub 监听或定时唤醒任务时，才列入待办。卡片显示最后一条助手消息，支持打开原会话；恢复工作或监听后自动移出。任一来源主机或子代理读取失败时显示错误，不把读取失败当作停滞。

## 浏览器自动同意与分组

配套浏览器扩展安装后默认自动点击 Claude Code 网页权限窗口的同意按钮，并按网页会话名称分组，无需配对。每个浏览器环境有独立身份；同名会话使用会话编号后缀区分。详细操作见 [扩展说明](browser-extension/README.md)。

扩展保留人工改名。如需让分组使用 Paseo 会话名称，可在高级设置中配对同一台电脑的 Paseo 插件。桥接仅监听本机回环地址，端口冲突时可在控制台改端口。名称同步默认关闭，不影响扩展独立工作。

自动点击根据网页可见按钮和权限文字识别弹窗，网页结构变更可能影响识别。扩展选项提供自动点击开关。网页提问接入 Paseo 需要一次配对；配对后出现在人工待办，并按在线／离线模式处理。未配对时保留独立分组和权限点击功能，不上传问题或代答问题。

## 暂停与恢复

「暂停 Paseo 模块」暂停问答处理、Paseo 名称同步和 GitHub 监听。浏览器扩展的自动点击需在扩展选项中关闭；停用扩展可同时停止点击和分组。某个 Paseo 模块失败时，其余模块仍更新。「恢复本页暂停前状态」仅在当前页面保留恢复点；关闭页面或刷新后，可分别启用所需模块。暂停不删除标签组。

## GitHub 订阅

GitHub 订阅插件每 60 秒检查一次仓库变化，把会话订阅的事件发给本机 Paseo 会话。默认使用影子模式：记录事件和匹配结果，不发送消息。

在「开发自动化」中打开「GitHub 订阅」，可查看订阅、最近事件和监听状态。在设置页保存 GitHub 令牌，检查「给会话注入 MCP 工具」已开启。令牌单独保存在本机权限为 0600 的文件中，界面只显示前缀、账号和额度。

会话可调用 `github_subscribe` 订阅仓库或具体 Issue/PR。订阅后，输入框上方显示 GitHub 胶囊。点击胶囊可查看或取消本会话的订阅。全局订阅页可按仓库或会话分组，并打开对应会话。

整仓库默认接收新建、关闭或重开，以及默认分支的 CI 失败和恢复。新提交和评审需要指定 PR。具体 Issue/PR 默认选择所有适用事件。`github_read` 可读取详情、评论、评审和 Actions CI；评论与评审支持分页。会话使用 `gh issue comment` 或 `gh pr comment` 发布用户已授权的评论时，按订阅工具描述在正文末尾添加当前会话标记，防止自己的评论通知自己。

确认影子事件正确后，在设置页关闭「影子模式」并保存。新事件会立即发送，同轮按会话合并。忙会话使用 steer；不支持 steer 的提供方默认允许回退中断，也可设置「跳过本轮」。Paseo 收到 steer 时会清除正在等待的提问或审批。

Mac mini 和 MacBook 各自保存设置、令牌和订阅。每台机器只向本机会话发送。取消订阅立即生效；归档会话会取消本会话订阅。关闭的 Issue/PR 三天后到期，期间重开会取消到期时间；连续十四天没有事件的订阅会清理。

## 云端会话

内置 `cloud-session` Provider 将云端会话映射为 Paseo agent，接收时间线并将面板提示和通知排队交给云端。它代理全部 Paseo MCP 工具，`create_agent` 的 `settings.modeId` 由调用方明确提供。注册与恢复使用本机 daemon，MCP 转发只连接 daemon 提供的本机 Paseo MCP 地址；凭据仅保存在进程内。无新增设置。

队列不持久化，插件或 daemon 重启会丢失未确认消息，也不自动对账；云端离线时轮次会持续显示运行中，直到云端结束它。GitHub 订阅与云端会话各自初始化。

## 浏览器环境剩余额度

已配对的浏览器环境在 Paseo 面板额度区域按环境名称展示 `claude.ai` 的 5 小时窗口和每周窗口剩余额度及重置时间。扩展在每个已配对浏览器环境中保持一个后台 `https://claude.ai/settings/usage`（跳转到 `/new#settings/usage`）用量页面标签页，每 10 分钟刷新该标签页并只读页面显示的额度比例与重置文字，每分钟通过本机 `/usage` 路由上报当前状态。用户把该用量标签页切走、改地址或关闭时，扩展不强行改回，下一轮读取时另开一个后台用量页面标签页。浏览器未打开、通道关闭、未登录或读取失败时，面板保留并展示上一次同步的额度与相对同步时间，超过三天未连接的环境自动移除。扩展不构造 `claude.ai` 请求，不点击任何页面，不刷新业务会话标签页，不切换账号，也不修改网页设置。
