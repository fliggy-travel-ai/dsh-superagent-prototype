# 会话分组与在线离线问答

在 Chrome 或 SunBrowser 扩展管理页打开开发者模式，选择“加载已解压的扩展程序”，加载本目录。安装或更新时会自动启用已经打开的 Claude 网页，无需刷新会话。

- 自动点击 Claude Code 网页权限窗口的“Allow once / Allow / 允许一次 / 允许”按钮。
- 自动按网页会话名称分组，多会话独立处理，保留人工修改的组名。
- 带作品面板参数或页面片段的会话标签也会分组；修改 Claude 会话名称后，分组名称自动同步。
- 安装后默认开启，不需要 Paseo 配对、令牌或逐会话授权。
- 在扩展选项中取消“自动点同意”可暂停点击；停用扩展可停止点击和分组。

权限点击仅匹配 Claude Code 会话页面中可见且可用的权限按钮，不点击问题选项或“Always allow”，也不解除按钮禁用状态。

要把网页提问送到 Paseo，在扩展选项中粘贴本机“开发自动化”插件提供的配对配置。配对后，网页提问出现在 Paseo 的“人工待办”。无需逐个绑定网页会话即可收取提问；会话绑定只用于关联组名。

- 在线：由 Paseo 在选定的声音来源主机播放提醒，等待用户回答。
- 离线：仅自动选择明确标记为推荐的选项，没有推荐项则等待用户回答。
- 自动：读取选定主机的手机蓝牙在场状态；状态过期、不可用或未知时不自动回答。
- 用户可在 Paseo 的“人工待办”选择答案并提交，扩展核对当前问题后点击一次。

未配对时不读取或上传问题，也不自动回答。连接失败会保留待回传结果和现有分组；结果未知时不重复提交。登录、两步验证、安全验证和权限扩大仍需用户处理。

网页问答识别目前支持带问题分组、单选或多选控件及唯一提交按钮的可见表单。尚未完成真实 Claude 问答页面验收；不符合结构的页面可能漏报。“已提交”表示扩展已点击提交，不表示网页确认接受。

扩展完整读取同一会话的全部标签页，确认问题不再显示后，人工回答自动移出待办；自动代答保留答案，直到用户点击“已读”。未知结果在完整扫描确认问题结束后也可移出，记录仍注明代答是否生效未确认。标签页关闭、读取失败、问题字段无效或数量超过上限时，不发送该会话的完整扫描标记，避免提前清除待办。

0.4.0 增加网页活动提示和权限动作同步。配对后，扩展读取正在输出、等待输入和用量限制提示，以及最后一条助手消息的末尾两千字。等待输入和用量限制显示在人工待办；不会自动发送继续消息或切换账号。从列表页进入会话无需刷新。多标签页中任一页面仍在输出时，优先报告运行中；读取不完整时不报告等待。

0.5.0 支持 claude.ai 真实提问卡片与 MCP 工具权限菜单：
- 识别 `[role="group"][data-approval-card-root]` 提问卡片及外层 `[data-tool-anchor]` 工具调用编号，支持单选、多选、“Other”自由文本输入（最长 2000 字符）与 `N of M` 多题分页逐页复核提交。
- 人工回答（`source: 'manual'`）不按敏感词拦截；离线自动代答仍按敏感词拦截且不填写“其他”自由文本。
- MCP 工具权限卡片无直接可见一次性按钮但存在“More allow options”按钮时，先预约再打开菜单，只点击文字为“Allow once”的菜单项；菜单中无该项时按 Escape 关闭并记为 `skipped`，永不点击“Always allow”。
- 云端会话的权限请求在 Paseo 中只作显示，由扩展在页面侧自动点“Allow once”。
- 权限卡片带阅读门槛（提示“Scroll to the end to allow this.”）时，只对本来就会自动批准的卡片先把参数区滚到底，确认提示消失后再点“Allow once”，记录 `readGate: read_gate_scrolled`；滚动后提示仍在时不点击，记 `skipped` 和 `readGate: read_gate_blocked`，按单卡重试上限停止。

权限点击会记录预约、窗口已消失、窗口仍显示或已跳过。配对后记录显示在插件最近动作中。窗口已消失只证明弹窗关闭，不证明命令成功。窗口仍显示时不会重复点击；同一命令在前一次窗口消失十秒后再次提出时，可以重新确认一次。带已勾选的永久授权控件、计划选择或无法辨认的窗口保留人工处理。

Paseo 的暂停会停止新问答处理；网页单次权限点击仍由扩展的“自动点同意”开关控制。停用扩展会停止全部浏览器功能。

配对后，扩展还会在后台维护一个 `https://claude.ai/settings/usage`（跳转到 `/new#settings/usage`）用量页面标签页，每 10 分钟只刷新这一个标签页并在加载完成后读取 5 小时窗口与每周窗口的用量比例和重置时间，每分钟通过本机 `/usage` 接口同步给 Paseo 面板显示（插件服务端通过 AdsPower 本地 API 查询环境名称，读不到时回退显示环境序号、`user_id` 或扩展配置的环境名称）。如果用户把该标签页切到其他地址或关闭，扩展不会强行改回，而是在下一轮读取时另开一个后台用量标签页。未配对时不打开或读取用量页面；扩展不构造 `claude.ai` 网络请求，不点击页面元素，不刷新业务会话页面，也不读取会话正文。
