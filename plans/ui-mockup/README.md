# GitHub 订阅插件交互界面稿

直接用浏览器打开同目录的 `index.html`。页面使用示例数据，不连接 GitHub 或 Paseo 守护进程。令牌检查、更换和设置项目前只展示设计，没有保存功能。

页面顶部可以切换浅色、深色、桌面、手机，以及正常和异常状态。画面包括会话页、订阅弹出层、订阅列表、事件列表、监听状态、设置页和两种空状态。

## 本地检查

2026-11-06，主会话使用 ego-browser 检查现有 Opus 5.5 原型产物：

- 胶囊可以打开本会话订阅列表。
- 取消一条示例订阅后，胶囊数量从 3 变成 2。
- 弹出层入口可以打开全局订阅页。
- 全局订阅页可以切换按仓库或按会话分组。
- 14 个桌面、手机、主题及异常状态组合成功渲染，页面没有整体横向溢出。
- 已目视检查桌面弹出层、深色订阅列表、事件列表、异常监听状态、异常设置页、手机弹出层、手机订阅列表和深色手机设置页。
- 已修复监听表格的异常说明被截断的问题，并移除“跳过本轮后等待空闲补发”的文案，遵循用户“不排队”的决定。

截图保存在 `screenshots/`。设置页和长列表可以在应用窗口内滚动。
