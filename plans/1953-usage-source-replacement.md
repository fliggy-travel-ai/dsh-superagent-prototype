# 额度来源去重与会话匹配修复

关联 Issue：fliggy-travel-ai/deepseek-harness#1953。

## 已完成的产品修改

- Claude 会话按实际环境读取登录目录，支持基础 Provider 名称和独立 macOS 用户。
- 会话环境优先于当前 Provider 配置；同一次发现只读取一次会话账号。
- Codex 按会话登录目录匹配配置账号；优先启用的候选配置。别名会话缺少环境时保留配置目录回退。
- 使用自定义 API 地址的 Codex 会话不展示本地订阅账号额度。
- 保留 Apple 登录账号的显示名称映射。

## 已核实的上游限制

安装版本的 `UsageSourceRegistry.register` 拒绝重复来源 ID。
内置插件在宿主启动时无条件加载，不受普通插件启用配置控制。
客户端公开 SDK 没有账号额度报告过滤接口。
当前产品适配层依赖的 Metro `getModules` 在正式客户端不可用。

会话额度映射还存在缓存限制：注册新来源不清除已有会话映射；注销来源只清除已经关联该来源的映射。旧空列表、仅包含官方来源的列表可能保留旧结果。

## 请求批准的最小扩展方向

在 Paseo 额度来源注册接口增加可选的“替代来源”声明，由宿主统一执行。产品插件继续负责账号识别、别名、额度读取和具体替代关系。

建议接口形态：

```ts
server.registerUsageSource({
  id: 'claude-accounts',
  replaces: ['claude'],
  discover,
  fetch,
});
```

宿主规则：

1. 只允许替代来源 ID 和稳定账号 key 同时匹配的报告。不同账号不能互相隐藏。
2. 自定义来源取得有效额度后，隐藏对应官方报告。自定义来源不可用时保留官方报告作为回退。
3. 全局查询、会话查询、指定报告查询及增量回调遵守同一规则。原来的固定项设置不被写坏，撤销替代后可恢复。
4. 注册或注销来源后清除会话发现映射，包括空映射，下一次查询重新发现。无需重启用户会话。
5. 未声明替代关系的插件保持原行为。

已定位的上游改动点如下。路径是安装包中的已核对路径；实现时修改对应源码，再构建安装包，不直接写入应用归档。

| 安装包路径 | 预计改动 |
| --- | --- |
| `@getpaseo/plugin/dist/server/usage.d.ts` | 在 `UsageSourceRegistration` 增加可选替代声明 |
| `@getpaseo/server/dist/server/server/plugins/plugin-process.js` | 注册元数据携带替代声明 |
| `@getpaseo/server/dist/server/server/plugins/plugin-process-protocol.js` | 校验并传递声明 |
| `@getpaseo/server/dist/server/server/plugins/index.js` | 将声明交给额度注册表 |
| `@getpaseo/server/dist/server/server/plugins/usage-sources/index.js` | 按账号选择报告，统一查询与回调；注册和注销时使会话映射失效 |

额度注册表还需增加针对性测试。指定报告 ID 的查询必须解析到对应可用替代报告；增量回调不能先把已经决定隐藏的官方报告发布出去。固定项是否还需要客户端通用解析适配须继续验证，不能把服务端过滤通过当作 UI 验收完成。

这份文件是待审批方案，不是已经实现的接口。最小范围为上述五处及测试；若验证证明还需扩展客户端协议，先补充具体差异供审阅。

产品侧配套：

- Claude 自定义来源接管默认账号及现有独立账号，不再依据官方目录是否存在判断是否读取默认账号。
- Codex 等来源使用与官方来源一致的稳定账号身份，Provider 别名只作为账号路由信息，不能作为跨来源账号身份。
- 移除依赖 Metro 模块扫描的隐藏方案，以宿主扩展的实际生效状态展示配置。
- 仅为实际启用、已完成身份匹配的替代来源声明接管。

## 验收条件

- Mac Mini 的同一 Apple 登录账号只显示一份，使用配置的显示名称。
- MacBook 同一个 Codex 登录账号只显示一份；不同登录账号仍各自保留。
- Claude 独立用户会话、Codex 多账号会话均按自身登录环境取得额度。
- 旧会话在插件重载后可重新发现额度，不要求重启会话。
- 停用自定义来源或额度读取失败时，官方回退仍可用。
- 全局列表、会话悬停和固定额度项显示一致。

## 部署边界

本轮未修改官方应用文件、未移动内置插件目录、未重启守护进程或用户会话。
上游扩展尚未实施，必须先取得用户批准。
