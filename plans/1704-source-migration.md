以 MacBook research 中的 claude-allow-guard 源码及已安装脚本为依据。早期 source-audit 和 integration-plan 是初始范围记录；本表包含用户后来授权的问答、语音和人工待办要求。

| 原方案能力 | 插件交付行为 |
| --- | --- |
| Glass 提示音、晓晓、afplay 音量 3 | 保留；神经语音失败回退 Flo，速率 200 |
| Python 模块、代理、合成超时 | 保留；ASKUSER_PYTHON、ASKUSER_VOICE 和来源主机代理；合成 25 秒、播放 30 秒 |
| 每题一次与 180 秒冷却 | 成功回执持久化，最多两千条；失败不记已提醒，冷却后可重试 |
| 阶段日志 | 最近语音回执显示提示音、合成、播放和回退结果；不输出代理或原始错误凭据 |
| 停止播报 | 新增按问题取消与跨主机取消；设置变化及问题结束触发取消 |
| 手机蓝牙在场 | 新增设备可选、精确地址或名称、配置版本匹配、稳定时长和未知状态 |

| 权限确认 | 原生精确会话策略和网页一次允许；保留回执，不使用永久授权 |
| 网页等待与用量限制 | 只读状态、末条消息和人工入口；多标签运行中优先、SPA 跳转可用 |
| 主会话停滞 | 核对跨主机子孙会话、提供方子代理、GitHub 监听和定时任务；读取失败不判停滞 |
| 窗口分组和标题同步 | 扩展独立分组、保留人工名称；配对可关联 Paseo 会话 |
| 自动换账号、无限续推、猜答案、Always allow | 不迁入；不符合当前授权范围 |
| 重复补点、解除按钮禁用、复活关闭标签 | 不迁入；未知结果不重发 |
| 原脚本凭据和账号数据 | 不复制、不提交 |
